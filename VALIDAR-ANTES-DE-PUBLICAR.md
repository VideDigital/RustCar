# Checklist — validar antes de publicar

## P0 — bloqueia publicação
- [ ] WhatsApp oficial confirmado e inserido em `site-config.js`.
- [ ] Domínio oficial definido e substituído no projeto.
- [ ] Portfólio real inserido ou seção de trabalhos ocultada.
- [ ] Serviços que serão anunciados confirmados diretamente com a Rust Car.
- [ ] Logo/identidade oficial validados.

## P1 — alto impacto
- [ ] Horário de atendimento confirmado.
- [ ] Google Business Profile revisado.
- [ ] Fotos reais da empresa inseridas.
- [ ] Avaliações reais adicionadas, caso disponíveis.
- [ ] CTA principal validado: orçamento, avaliação ou envio de fotos pelo WhatsApp.
- [ ] Teste completo no celular.
- [ ] Teste dos links de WhatsApp, Instagram e Maps.

## Tracking
- [ ] GA4 configurado.
- [ ] GTM configurado, se utilizado.
- [ ] Meta Pixel configurado, se utilizado.
- [ ] Evento de clique no WhatsApp testado.
- [ ] Processo comercial definido para registrar lead → orçamento → venda.

## SEO
- [ ] Title e meta description revisados.
- [ ] Canonical atualizado.
- [ ] `robots.txt` atualizado.
- [ ] `sitemap.xml` atualizado.
- [ ] Schema revisado com dados oficiais.
- [ ] Páginas de serviços criadas somente para serviços confirmados e prioritários.
